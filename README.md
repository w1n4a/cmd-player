# 🎵 CMD Player

Программа для настоящих любителей консольных приложений! 🚀  
Просто добавляй свои любимые песни в плейлист (поддерживается только `.mp3`) и кайфуй под треки прямо в терминале. 🎧Все доступные команды можно посмотреть через `help`. ✨

### 🕹️ Команды:
* `play [name]` — включить песню из плейлиста.
* `stop` — выключить песню.
* `pause` — поставить на паузу.
* `unpause` — убрать паузу.
* `list` — посмотреть плейлист.
* `help` — вызвать это меню.

---
⚙️ *Создано на Python с библиотекой PyGame*
